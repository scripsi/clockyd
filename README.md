# clockyd
ClockYD - Just a clock on a cheap yellow display

## Introduction

Hmm, so yet another clock then? Well, yes, but this one does have a special purpose: to be readable when I'm not wearing my glasses.

I find most clocks unreadable without my glasses on (for example, at night when I'm in bed) because my main sight defect is astigmatism - a deformation of the eyeball that creates multiple focal points for an image. This makes things look fuzzy at _any_ distance, so simply making a bigger clock or moving it closer to read it doesn't help! A normal analogue clock becomes multiple overlapping clock faces, making it impossible to distinguish the hour and minute hands, while the numbers on a digital clock are smeared and superimposed making them illegible.

My glasses use aspherical lenses that correct the multiple focal lengths of my eyes to create a single coherent image. Obviously I can't do this with a flat LCD screen, so how can I make it more readable?
